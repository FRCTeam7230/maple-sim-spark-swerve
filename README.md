# maple-sim-spark-swerve
Simulation of real physics using maple-sim. Code is based on [AdvantageKit SparkMax Swerve Template](https://github.com/Shenzhen-Robotics-Alliance/maple-sim/tree/main/templates/AdvantageKit_SparkSwerveTemplate-maple-sim).


# Guide for how to this setup
1. Download wpilib vscode, be sure to have advantage scope downloaded with it (current is 2025 but you might be in 2027)
2. Download this and open it using wpilib.
3. Press the top-right wpilib icon to open up a list of commands, and click simulate robot code (you may need to do build robot code first)
4. Open advantage scope while you're waiting for it to open (advantage scope takes a weirdly long time to open for me, and just doesn't open sometimes)
5. When it askes you if you want any other extentions, only choose "Sim GUI" but that should be chosen for you automatically.
6. Then it opens up a "robot simulation" screen, set it to teleoperated.
7. In advantagescope click the top right file button, then click connect to simulator
8. Switch advantage scope to 3D Field
9. Drag Robot position, elevator sim, and coral from the left side to the poses area in the middle-bottom
10. They may not be the values you see in the beginning, but you need to right click on the icon and switch it to the proper values.
11. To get the Team7230 bot, you need to go to the top left help button and click show assets.
12. Then keep the folder for assets in mind and drag maple-sim-spark-swerve/assets/Robot_Team7230 folder into the assets folder.
13. Then right click the icon for the robot position and now you should be able to see Team7230 as a robot.
